# 批量混剪

一个 Windows 上用的批量混剪小工具。

把素材按镜头分好文件夹（比如：开头 → 痛点 → 产品 → 结尾），它会从每个文件夹里各挑一条，按顺序拼成一条视频，一次能出几百条，而且每条的组合都不一样。

## 它能做什么

- **顺序不会乱**：文件夹排第几，这段就在视频的第几段。
- **不会撞视频**：每条成品的素材组合都不重复，以前混过的组合下次也会自动避开。
- **素材用得平均**：不会某几条素材被反复用、另一些一直轮不到。
- **快**：素材规格一样的话，不重新编码，直接拼，一条零点几秒。几百条一两分钟就出完。
- **有清单**：每批会导出一份【恺研发定制】清单（CSV），能查到每条成品用了哪几条素材。
- 等的时候还能玩两个小游戏：贪吃蛇，和可以局域网 4 人联机的坦克混战。

## 怎么用

**第一次：**

1. 把整个文件夹放到一个固定的位置，比如 `D:\批量混剪`。放好之后就别再挪了。
2. 双击 `双击运行.bat`。

第一次会自动把需要的东西装好（Python、界面组件、ffmpeg），要联网，等几分钟。装好后桌面上会多一个「批量混剪」图标，程序也会自己打开。

**以后：** 直接双击桌面上的「批量混剪」。

**混一批视频：**

1. 左边点「从父文件夹导入子文件夹」，选装着各个分镜文件夹的那个大文件夹。也可以把文件夹直接拖进窗口。顺序不对就用「上移 / 下移」调。
2. 右边填要生成几条。下面会显示最多能组合出多少种、还剩多少种没用过。
3. 选好输出文件夹，点「开始处理」。

## 几个要知道的

- **素材最好统一规格导出**（比如都是 1080×1920、30 帧）。这样全部直接拼，最快。有个别不一样的，程序会先把那几条转一下再拼，日志里会写清楚是哪几条、差在哪。
- **「强制直接拼接」**：打开后一条都不转，最快，但规格不一样的素材拼出来可能会卡顿或花屏。只在你确定素材没问题时用。
- **缓存**：转过的素材会存起来，下次直接用。换了一组文件夹时会自动清掉，平时不用管。
- **越混越慢？** 多半是硬盘写不过来了，不是软件的问题。输出到更快的硬盘会好很多。
- **出错了**：会弹窗提示，详细信息在 `data\error.log`。

## 发给别人用

两种办法：

- 直接把这个文件夹发过去，对方也双击 `双击运行.bat`，一样会自动安装（要联网）。
- 或者先双击 `打包exe.bat`，把生成的 `dist\BatchMixCut` 整个文件夹发过去。对方双击里面的 `BatchMixCut.exe` 就能用，什么都不用装。

不要把你自己正在用的整个文件夹打包发人，里面的 `.venv` 和 `data` 是你自己电脑的运行环境和记录，别人用不了。

## 支持的系统

64 位的 Windows 10 / 11。

## 给想看代码的人

用 Python + FFmpeg 写的，界面是 PySide6。

```
main.py            程序入口
cli.py             命令行版本（python cli.py --help 看用法）
双击运行.bat        一键安装并运行
打包exe.bat         打包成 exe
mixcut/
  gui.py           界面
  engine.py        整个流程：扫描 → 检查规格 → 排组合 → 拼接
  combo.py         组合不重复、素材用得平均的算法
  concat.py        调 FFmpeg 拼接
  preprocess.py    转换规格不一样的素材、缓存
  game.py          小游戏界面
  lan_game.py      坦克游戏的规则和局域网联机
tests/             自测脚本：生成测试素材、逐帧检查成品顺序和音画同步
```

几个实现上的点，简单说一下：

- **组合不重复**：每种组合对应一个编号，直接一次抽出 N 个不重复的编号再换算回素材，不用"撞了重抽"，几亿种组合也是一瞬间。
- **直接拼接**：以这批素材里多数的规格为准，规格一样的用 FFmpeg 直接复制数据流拼起来，不重新编码。帧率或时间基不一样的直接拼会卡顿，所以这几条会先单独处理。
- **成品只写一遍硬盘**：成品文件开头提前留好索引的位置，写完直接填进去，不用像平常那样把整个文件再搬一遍。

需要 ffmpeg 时，`双击运行.bat` 会自动下载。想手动装的话，从 https://www.gyan.dev/ffmpeg/builds/ 下载，把 `ffmpeg.exe` 和 `ffprobe.exe` 放进 `ffmpeg` 文件夹就行。
